# Urban Flood Nowcasting

A real-time urban flood prediction and nowcasting system for smart city flood risk management.

## Project Structure

- `docs/`: Comprehensive project documentation and design analyses.
- `frontend/`: Web visualization portal & dashboard.
- `backend/`: API services and data ingestion pipelines.
- `flood-engine/`: Core flood modeling & nowcasting engine.
- `data/`: Datasets (raw, processed, sample).
- `models/`: Trained machine learning & hydrological models.
- `scripts/`: Data fetching, preprocessing, and utility scripts.
- `tests/`: Unit and integration test suites.
- `.github/workflows/`: CI/CD automation pipelines.
